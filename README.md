## What SHADOW_NET Is

Community-owned AI-powered security system designed for **infrastructure resilience** and **privacy sovereignty**:

### Core Innovation (Prior Art - Published Feb 19, 2026)

- **14-Day Battery Autonomy** - LiFePO4 batteries (150Ah) + N-Type bifacial solar panels. System operates 14 days without grid, internet, or cellular. [Prior art claimed]

- **Unjammable Multi-Layer Communications** - Four-tier fallback architecture:
  1. WiFi mesh (primary, 300m range)
  2. Bluetooth Low Energy mesh (secondary, 100m range)
  3. LoRa WAN (tertiary, 5km range)
  4. Software-Defined Radio with frequency hopping (emergency, configurable) [Prior art claimed]

- **Hybrid AI Architecture** - Edge processing (CodeProject.AI) for real-time threat detection + central SENTINEL server for pink noise pattern filtering and threat correlation. Zero cloud dependency. [Prior art claimed]

- **Pink Noise Filtering** - AI-trained to recognize "normal chaos" (kids playing, dogs running, deer at night) vs. actual security events. Reduces false alarms >90%. [Prior art claimed]

- **Community-Controlled LE Access** - Five policy tiers (No Access → Full Integration). **Community decides**, not government mandate, not corporate policy. [Prior art claimed]

### Technical Specifications

**Hardware:**
- 17 solar-powered nodes (expandable to 29+)
- SV3C PTZ cameras (future: US-manufactured NDAA-compliant)
- LiFePO4 batteries (pure DC system, no inverters)
- N-Type bifacial solar panels (optimal for Arkansas climate)
- Ubiquiti network infrastructure (mesh topology)

**Software:**
- CodeProject.AI (local edge processing)
- BlueIris / custom NVR (central recording)
- OpenCV-based motion detection
- Custom pink noise filtering algorithms
- Multi-camera threat correlation

**Network Architecture:**
- VLAN segmentation (cameras isolated from home networks)
- TRENDnet NDAA-compliant switches
- Ubiquiti wireless mesh backbone
- LoRa WAN for disaster scenarios
- SDR emergency fallback

**Coverage:**
- 56 families, 17 acres
- Focus: ASH ZONE (creek, playground, common areas)
- Scalable: 100-200 home communities

## Why SHADOW_NET Exists

### The Problem (Three Failures)

**1. Corporate Cloud Surveillance (Ring, Nest, ADT)**
- Subscription dependency (monthly fees forever)
- Data leaves community (cloud processing, corporate ownership)
- Privacy violations (law enforcement backdoor access without consent)
- Internet dependency (system fails when internet fails)

**2. No Alternatives for 100K+ Communities**
- Gated communities, HOAs, rural towns need infrastructure security
- Enterprise solutions (Axis, Bosch) too expensive ($2,700/camera)
- DIY solutions require technical expertise
- **No turnkey, community-owned option exists**

**3. Economic Opportunity Lost**
- Security jobs exported (Chinese manufacturing)
- Rural tech jobs nonexistent ("we don't have tech jobs here")
- Youth workforce underdeveloped (no career pipeline)

### The Solution (SHADOW_NET)

**Community Sovereignty:**
- Community owns the data (stays local, never cloud)
- Community controls access (5 policy options, they choose)
- Community governs system (not corporate, not government)

**Infrastructure Resilience:**
- Works when grid fails (14-day battery)
- Works when internet fails (local processing)
- Works when cellular fails (LoRa, SDR backup)
- **Designed for disaster scenarios**

**Economic Development:**
- Youth workforce training (paid positions, not volunteers)
- Rural tech jobs (installation, maintenance, monitoring)
- US manufacturing pathway (NDAA-compliant cameras, Arkansas)
- **Reverses brain drain, creates careers**
